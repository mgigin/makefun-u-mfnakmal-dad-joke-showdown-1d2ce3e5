# Dad Joke Showdown

An entry for the make.fun bounty **Dad Joke Showdown**: one dad joke, at most 200 characters, written to `/output/entry.txt`.

## The entry

> My wife asked why I bring a ladder to every barbecue. I said I like to raise the steaks.

## Run

```sh
node main.ts
```

No dependencies, no network. The program validates the joke against the gate (1–200 characters, a single line, not only whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output/entry.txt` and then `./output/entry.txt`.
